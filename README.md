คู่มือการใช้งาน UI

    วิธีการใช้งาน
    
        ต้อง cd เข้าในโฟลเดอร์ที่มีไฟล์งานของเรา (ในงานนี้ใช้ .html, 
        .js, .css) จากนั้นใช้คำสั่ง python -m http.server 8000 
        ใน therminal

    โหมดการทำงาน (แถบบน):

        Image Mode: กดปุ่ม + Upload Image เพื่อเลือกรูปภาพเข้ามาวิเคราะห์

        Live Cam: คลิกเพื่อสลับไปใช้กล้อง Webcam ตรวจจับแบบ Real-time

    การตั้งค่า (Inspector & Settings):

        Max Results: ปรับจำนวนวัตถุสูงสุดที่ต้องการให้ตรวจจับ (1 - 10 ชนิด )

        Score Threshold: ปรับระดับความแน่ใจขั้นต่ำของ AI (0.00 - 1.00)

        Hardware Delegate: เลือกการประมวลผล (แนะนำ GPU Accelerated จะเร็วกว่า CPU)

ขั้นตอนการทำงาน

    ดึงภาพสด: เบราว์เซอร์ดึงเฟรมภาพจากกล้อง Webcam ผ่าน HTML5 Video API

    ส่งเข้า Task: JavaScript นำเฟรมภาพนั้นส่งไปให้ MediaPipe Task (ObjectDetector) ประมวลผล

    AI วิเคราะห์: โมเดล AI คำนวณหาตำแหน่งประเภทวัตถุ

    ส่งค่ากลับ: AI คืนค่าผลลัพธ์เป็นพิกัดกรอบ (Bounding Box Coordinates), ชื่อวัตถุ (Label), และค่าความมั่นใจ (Confidence Score)

    วาดผลลัพธ์: JavaScript นำพิกัดที่ได้ไปวาดเป็นกรอบสี่เหลี่ยมและป้ายชื่อทับลงบน Canvas บนหน้าเว็บทันที
        
ข้อจำกัด

    ประสิทธิภาพขึ้นอยู่กับเครื่องผู้ใช้ (Client-Side)

        - เนื่องจากประมวลผลบนเบราว์เซอร์ หากเครื่องไม่มี GPU หรือเป็นคอมพิวเตอร์สเปกต่ำ การรันในโหมด Live Cam อาจมีอาการกระตุกหรือ FPS ตกได้
        
    ข้อจำกัดของโมเดล EfficientDet-Lite0

        - ตรวจจับวัตถุได้เฉพาะ 80 ประเภทตามมาตรฐาน COCO Dataset (เช่น คน, สุนัข, รถยนต์, ขวดน้ำ ฯลฯ) ไม่สามารถตรวจจับวัตถุเฉพาะทางอื่นๆ ได้

        - ความแม่นยำจะลดลงหากวัตถุอยู่ไกลเกินไป แสงน้อย หรือโดนบดบังบางส่วน
